# Changelog

## Installer update — 2026-10-19

- Added MIT-licensed Inno Setup source and build script.
- Added current-user Setup.exe, optional desktop shortcut, Start menu and uninstall registration.
- Installer checks WebView2 availability and preserves browser profile data on uninstall.
- Tested installation, shortcuts, installed app self-test and uninstallation.

## 0.3 — 2026-10-19

- Renamed Minti to Minit; added an original logo and executable icon.
- Replaced the classic native title bar with a custom rounded frame and window controls.
- Added an optional translucent outer rim without making website text transparent.
- Included build instructions, validation output and bundled third-party notices.
- Preserved earlier preferences through non-destructive metadata copying; cookie sessions are not migrated.

## 0.2

- Dark/light themes, persistent settings, search-engine selection, zoom, download folder, local history and bookmark management.

## 0.1

- Initial WebView2 shell with tabs, background unloading and session-address storage.
